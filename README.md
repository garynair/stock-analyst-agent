# Stock Analyst Agent

A multi-agent AI system for stock research and analysis — agents collaborate to gather data, run research, and produce structured investment analysis.

## Structure

- `agents/` — individual agent definitions (research, analysis, scoring, etc.)
- `framework/` — orchestration and shared agent framework code
- `input/` — input data and configuration
- `output/` — generated analysis output
- `research/` — supporting research material
- `v1_portfolio_state_starter_template.xlsx` — starter template for tracking portfolio state
